# Emirhan Kaya — Python Projects

[English](README.md) | [Türkçe](README_TR.md)

This profile repository contains a collection of small Python utilities and learning projects covering text processing, computer vision, audio, PDF conversion, QR codes, algorithms, and desktop automation.

## Selected topics

- Text cleanup, paragraph splitting, and summarization
- Password and QR-code generation
- PDF-to-text and image-to-text tools
- License-plate detection and image-processing experiments
- Audiobook utilities
- Sorting algorithms, sets, and coordinate exercises
- YouTube playlist link extraction

The projects were created at different stages of learning, so requirements and execution methods may vary by script. Review a script before running it and use a virtual environment for third-party dependencies.
