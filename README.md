## Featured projects

### [YOLO Buoy Detection](https://github.com/emirhankaya-AFK/emirhankaya/tree/main/yolo-buoy-detection)

A computer-vision workflow for detecting buoys and navigation marks in images. It includes auto-labelling, dataset validation, label correction and a YOLO training pipeline.

**Tech:** Python, Ultralytics YOLO, PyTorch, OpenCV  
**Run:** pip install ultralytics opencv-python torch → configure data.yaml → python train_yolo.py

### [Face Recognition System](https://github.com/emirhankaya-AFK/emirhankaya/tree/main/face-recognition-system)

An OpenCV application that loads known profiles, detects faces with Haar Cascades and compares test images against reference images.

**Tech:** Python, OpenCV, Haar Cascade  
**Run:** pip install opencv-python → place reference images in fotograflar/ and test images in yuz_tanima/ → python yuz_tanima.py

### [Etsy Collection Scraper](https://github.com/emirhankaya-AFK/emirhankaya/tree/main/etsy-perfect-scraper)

A Playwright-based scraper for JavaScript-rendered Etsy collections. It saves high-resolution product images and structured metadata, produces summary files and can record the browsing session.

**Tech:** Python, Playwright, browser automation, optional FFmpeg  
**Run:** pip install playwright → python -m playwright install chromium → set TARGET_URL in scraper.py → python scraper.py

### [Flask + PyQt Flight Log Explorer](https://github.com/emirhankaya-AFK/emirhankaya/tree/main/PYQT5%2BFLASK%20TABANLI%20U%C3%87U%C5%9E%20LOGU%20SORGULAMA%20VE%20ROTAYI%20%C3%87%C4%B0ZD%C4%B0RME)

A desktop/client-server project for querying flight logs and visualising routes from JSON data through a Flask service and PyQt interface.

**Tech:** Python, Flask, PyQt5, JSON  
**Run:** install Flask and PyQt5, start Flask Sunucusu.py, then run PyQt5 Arayüzü.py.
